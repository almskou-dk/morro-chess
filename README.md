# ♟️ MORRO — Mundo del ajedrez

> **Estrategia. Precisión. Pasión por el juego.**

MORRO — Mundo del ajedrez es una tienda especializada en productos relacionados con el ajedrez y la cultura del juego estratégico. El proyecto está diseñado para ofrecer una experiencia moderna, elegante y profesional para jugadores principiantes, aficionados, coleccionistas y amantes del ajedrez.

La tienda reúne una selección de tableros, piezas, relojes, accesorios, artículos para entrenamiento y productos pensados para disfrutar el ajedrez tanto en casa como en competición.

---

## ♟️ Sobre MORRO

MORRO nace con una idea sencilla:

**Convertir cada partida en una experiencia.**

El ajedrez combina estrategia, creatividad, concentración y disciplina. MORRO busca reflejar esos valores mediante una identidad visual elegante y una tienda organizada alrededor del mundo del ajedrez.

Desde un tablero clásico para comenzar a jugar hasta accesorios para jugadores más experimentados, el catálogo está pensado para diferentes estilos y niveles.

---

## 🎯 Objetivos del proyecto

- Crear una tienda especializada en ajedrez.
- Ofrecer una navegación clara y moderna.
- Presentar productos de forma visual y organizada.
- Facilitar la exploración por categorías.
- Crear una experiencia atractiva para jugadores de diferentes niveles.
- Mantener una identidad visual elegante y reconocible.
- Desarrollar una base preparada para futuras funcionalidades de comercio electrónico.

## 🛒 Carrito de compras

El proyecto incorpora una estructura de carrito preparada para gestionar productos seleccionados por el visitante.

Entre sus funciones se contemplan:

- Añadir productos.
- Eliminar productos.
- Modificar cantidades.
- Visualizar el contenido del carrito.
- Calcular subtotales.
- Mantener la selección durante la navegación.

La arquitectura puede ampliarse posteriormente para conectar el proyecto con un sistema real de pagos.
